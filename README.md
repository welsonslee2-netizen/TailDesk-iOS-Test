# TailDesk 0.13

支持 Tailscale 与局域网直连的 Windows 远程桌面原型。一个 EXE 同时提供控制端和被控端；可选临时码确认或无人值守密码连接。

0.13 在现有低延迟控制、无人值守、文件传输、移动端键鼠、横屏与剪贴板同步基础上，新增 Windows 内置 EasyTier 国内 P2P 组网和 iOS 配置导入。本版交付 Windows 与 iOS，不更新 Android。完整部署教程见 `TAILDESK_013_DEPLOYMENT.md`。

## 0.13 国内 P2P 快速开始

1. 解压 `dist/TailDesk-0.13-win-x64.zip`，保留 `easytier` 子目录，以管理员身份运行 `TailDesk.exe`。
2. 打开“控制 / 国内 P2P 设置”，点击“生成新网络”，设置无人值守密码并保存。
3. 启动国内 P2P，选择标有 `EasyTier 国内 P2P` 的地址，再开启被控。
4. iOS TailDesk 点击“国内 P2P 配置”，导入 Windows 复制的 `TDNET1` 配置。
5. iPhone 的 EasyTier 网络上线后，使用电脑虚拟 IP和 `59011` 端口连接。

EasyTier 网络密钥由 Windows DPAPI 加密保存，并通过环境变量传递给内置核心。Windows 端无需另装组网软件。iOS 系统级虚拟网卡依赖 Network Extension entitlement，个人免费签名环境下由 EasyTier iOS 提供。

## 原有控制功能操作

### 桌面控制修复

- 普通字符改走 Unicode 文本输入，Ctrl/Alt 组合键、方向键、功能键继续走虚拟键按下/释放链路，解决只按下不释放以及字符不落入远程窗口的问题。
- 远端鼠标不再烘焙到每张全屏图片；控制端使用本地即时指针，消除延迟指针叠加造成的重影，也避免仅移动鼠标就触发全屏编码。
- 主窗口取消覆盖卡片内容的底部悬浮按钮，手机浏览器地址现在可完整滚动显示和复制。

### 清晰度与速度

远程窗口顶部可选择：

| 模式 | 分辨率与编码 | 目标最高帧率 |
| --- | --- | --- |
| 文字清晰（默认） | 主屏原分辨率 PNG 无损；单边 4096、总像素 900 万上限 | 12 fps |
| 均衡 | 最大宽度 1920，JPEG 质量 86 | 20 fps |
| 流畅 | 最大宽度 1280，JPEG 质量 70 | 25 fps |

点击“原尺寸查看”按像素显示，窗口较小时通过滚动条移动查看；点击“适应窗口”恢复缩放。原尺寸可避免缩放导致小字变糊。

实际帧率取决于画面变化、编码耗时和网络。无损模式流量通常更高，慢网可选择均衡或流畅。静态画面减少重复编码，约每秒强制刷新一次；每帧确认后才发送下一帧，避免积压旧画面。输入独立反向处理。

自动尝试 DXGI / D3D11 GPU 屏幕采集，失败时回退 GDI，状态栏和记录中显示后端。**目前硬件加速覆盖采集，JPEG/PNG 编码仍由 CPU 完成；没有 NVENC、QSV、AMF 硬件编码。**

### 连接历史与名称

认证成功后自动获取 Windows 电脑名，记录 IP 和端口。主窗口“连接历史”可选已有设备；“自定义名称”填写备注，下次成功连接后保存。同一 IP + 端口自动合并，保留最近 30 项，不保存配对码或密码。

设置保存在当前用户 `%LOCALAPPDATA%\TailDesk\settings.xml`。

### 无人值守密码

1. 被控端停止会话，点击左侧底部固定的“控制 / 国内 P2P 设置”。
2. 设置两次相同的 12–128 字符密码，勾选“启用无人值守密码控制”，保存，再开启被控。
3. 控制端勾选“使用无人值守密码”，输入 IP、端口和密码，连接后直接控制，不弹出对方确认。
4. 临时配对码仍需对方确认。关闭无人值守：停止被控，在设置中取消开关，再重新开启。
5. “启动 TailDesk 时自动开启被控”会在程序启动且原监听地址存在时自动监听。它不设置 Windows 开机启动，也不安装系统服务。

使用 PBKDF2-HMAC-SHA256 派生凭证，由 Windows DPAPI 当前用户加密保存，不把原密码写入配置或历史。连续 5 次错误触发 30 秒冷却。

被控电脑需要 TailDesk 正在运行，所选局域网、EasyTier 或 Tailscale 链路已连接。无人值守去掉的是连接确认；锁屏采集失败时会保持会话并发送状态画面，也会尝试切换到当前输入桌面，但稳定控制登录密码框、UAC 和重启后未登录场景仍需要后续 Windows 系统服务。停止被控同时结束电脑和手机会话。

### iPhone / iPad / 安卓控制

提供内置浏览器客户端和 iOS 原生 App；旧版 Android 包保留但本版未更新。iOS 支持触控板、屏幕直触、仅浏览、双指缩放/平移、虚拟左右键、拖动锁定、滚轮、文字输入和自动画质。

同一 Wi-Fi 下，在电脑端监听地址选择标有“局域网直连”的 `192.168.x.x`（或其他私网地址），手机使用窗口显示的该地址和手机端口连接。此路径绕开 Tailscale DERP 中继，通常具有最低延迟。外网仍可选择标有“Tailscale”的 `100.x.x.x` 地址。

1. 外网可按 `TAILDESK_013_DEPLOYMENT.md` 使用 EasyTier 国内 P2P；原有 Tailscale 方式继续兼容。
2. 被控端设置中同时勾选密码控制与手机入口，保存并开启被控。
3. 左侧“手机浏览器地址”和日志显示入口，例如 `http://100.101.102.103:59011/`。手机端口为主端口 + 1。
4. 用 Safari / Chrome 打开地址，输入同一个无人值守密码。
5. 浏览器端点击“键盘”会唤起手机输入法；选择“触控板 / 虚拟鼠标”“触屏直点”或“仅浏览 / 平移”。双指可缩放和平移，缩放范围 25%–800%。
6. iOS 源码在 `mobile/ios`，为原生 SwiftUI/UIKit 实现。按 `mobile/ios/README.md` 在 macOS 的 Xcode 中选择自己的开发团队后运行或归档。
7. 没有 Mac 时，可按 `IOS_WINDOWS_INSTALL.md` 使用 GitHub Actions 免费生成未签名 IPA，再由 Windows AltServer 使用个人 Apple Account 签名安装。

手机入口需额外放行 TCP `59011`（或实际主端口 + 1），Windows 防火墙需要允许。Tailscale 模式由 Tailscale 加密；局域网直连模式面向可信 Wi-Fi，当前移动协议没有额外 HTTPS。程序拒绝直接绑定或连接公网 IPv4，请勿做公共端口转发。

默认禁用手机入口。会话使用 HttpOnly / SameSite Cookie 和 CSRF 校验，无请求闲置约 2 分钟自动结束。电脑和手机共用单个控制会话名额。

手机端当前不包含文件传输。iOS 0.13 由 GitHub Actions 的 macOS/Xcode 环境编译，最终真机仍需个人签名。

## 运行

要求：Windows 10/11 x64、.NET Framework 4.8 或更新的 4.x 版本。EasyTier Windows 核心已随 ZIP 集成；Tailscale 仅在继续使用旧网络方式时需要。

在两台电脑上复制并保留以下两个文件，双击 EXE：

```text
bin/0.13/
  TailDesk.exe
  TailDesk.exe.config
```

也可解压 `dist/TailDesk-0.13-win-x64.zip` 后运行。默认不安装服务、不自动监听，不设置 Windows 开机启动。源码输出在 `bin/0.13`，旧版保留。

## 两台电脑连接

1. 两台电脑安装 Tailscale 并登录，加入允许互相访问的 tailnet。先确认 `tailscale ping 对方的TailscaleIPv4` 可通。
2. 在被控电脑启动 TailDesk，选择其 Tailscale IPv4，默认端口为 `59010`，点击“开启被控”。
3. 将地址、端口和本次 32 位配对码交给控制方。配对码只显示在窗口内，不写入文件和日志。
4. 控制方启动 TailDesk，填写地址、端口、配对码，点击“连接远程电脑”。
5. 被控方会收到确认窗口，直接点击“允许远程控制”或“仅观看”，也可拒绝连接。30 秒无响应则自动拒绝。
6. 选择“允许远程控制”后，控制端自动启用鼠标键盘，点击远程画面即可操作。顶部显示“远程控制已启用”，需要暂时停止输入时勾选“暂停控制”。
7. 控制方点击“断开连接”或在远程窗口按 `Ctrl+Shift+F12` 结束；被控方点击“停止被控 / 断开”同时停止监听并使配对码失效。

被控端开启期间，已知本次配对码的设备可以再次申请连接；每次仍需本机确认。停止后重新开启会生成新码。当前只允许一个连接申请或会话占用被控端。

### 只有画面、操作无效时

- 窗口标题应为 `TailDesk 0.13`。旧版需要二次授权的流程已去掉。
- 远程窗口顶部显示“当前仅观看”时，点击“申请控制”；被控方再次确认“允许远程控制”后自动生效。
- 已获准后，确认“暂停控制”未勾选，点击画面使其获得键盘焦点。
- 底部会显示被控端实际输入执行反馈。若 Windows 拒绝输入，画面会继续显示，并给出具体错误；程序不会把权限问题默认为网络断开。
- 控制管理员窗口时，在**被控电脑**主窗口点击“以管理员身份重启”，由本机用户处理 UAC 提示，随后重新开启被控并使用新配对码连接。重启前需停止现有会话。普通窗口通常无需提升权限。

### 双向文件传输

- 控制方向被控方发送：在远程画面窗口顶部点击“发送文件”，选择一个文件。
- 被控方向控制方发送：在被控端主窗口点击“向控制端发送文件”。
- **接收方每次选择保存位置才开始接收**；取消保存对话框即拒绝本次文件。不要选择已有文件，程序会保留已有文件并要求改名。
- 文件进度与完成结果显示在控制端底部状态栏、被控端会话记录中。任一方可点击“取消传输”或“取消文件传输”。
- 同时支持每个方向各一个文件；单个文件上限 8 GiB。采用 64 KiB 分块、逐块确认和 SHA-256 完整性校验，不把整个文件装入内存。
- 接收中使用同目录 `.part` 临时文件，验证长度和哈希通过后才生成最终文件。正常取消、断线、错误校验会清理临时文件；程序或系统强制终止时可能遗留 `.taildesk-*.part`，确认不再传输后可手动删除。
- 不自动执行接收的文件，不提供远程目录浏览、文件夹传输、断点续传或拖拽传输。接收确认约 110 秒超时；已弹出的保存对话框仍需本机用户关闭，超时后不会继续保存。
- 文件复用当前已认证连接，无需额外开放端口。慢网下文件传输仍会竞争画面带宽。

### 网络规则

被控端需要在 Windows 防火墙和 Tailscale Grants/ACL 中允许控制端访问 TCP `59010`（若改端口则同步修改规则）。只开放给需要的控制设备或用户。程序绑定具体 Tailscale 网卡 IPv4，不绑定 `0.0.0.0`，不需要路由器公网端口转发。

本项目不自动修改防火墙、Tailscale 登录状态或访问策略。Tailscale 规则与 Windows 防火墙须同时放行。

在控制电脑的 PowerShell 中检查：

```powershell
tailscale ping 100.101.102.103
Test-NetConnection 100.101.102.103 -Port 59010
```

把示例地址替换为被控端真实地址。`tailscale ping` 通但 TCP 端口不通时，检查程序是否开启监听、地址和端口是否一致，以及两层访问规则。直连与中转路径的性能差异请通过实际网络测试评估。

## 本机测试

启动两份程序。第一份选择 `127.0.0.1 (本机测试)` 并开启被控，第二份连接 `127.0.0.1` 和相同端口，填写第一份的配对码。

本机测试建议只选择观看；同一桌面查看自身会形成画面递归，启用控制还可能将注入事件重新送入控制窗口。实际控制测试请使用两台电脑。

## 构建与测试

无需下载 NuGet 包或 SDK，使用 Windows .NET Framework 自带的 C# 编译器：

```powershell
.\build.ps1
.\test.ps1
```

构建前关闭正在运行的 TailDesk。`test.ps1` 重新构建程序并执行本机自检，结果写入 `artifacts/self-test.txt`。测试需要允许本机回环套接字和访问交互式桌面。

目前 79 项自检覆盖 GPU/回退采集、PNG/JPEG、真实 TCP 握手、帧确认前断线释放、控制、无人值守密码、DPAPI 和历史、双向文件、手机认证及图像输入接口、CSRF、跨来源请求和登出。

有 Node.js 时，运行 `node .\check-mobile.cjs` 检查手机 JavaScript 语法与元素引用。

输入测试使用 DryRun 或原生调用替身，验证 Win64 结构大小、成功和失败路径，不向用户当前窗口注入实际按键。真实鼠标键盘、不同权限窗口和 DPI 仍需在两台电脑上测试。

## 当前实现与边界

| 项目 | 当前行为 |
| --- | --- |
| 界面 | C# / WinForms，双端同一程序，中文界面 |
| 采集 | DXGI/D3D11 GPU 采集，失败回退 GDI，主屏及光标 |
| 画面 | 无损 PNG / 高清 JPEG 三档，原尺寸查看，帧确认限制积压 |
| 传输 | 单个双向 TCP 连接，画面与输入在不同传输方向并发处理 |
| 输入 | 归一化坐标、左/右/中键、拖动、滚轮、常见虚拟键 |
| 控制授权 | 被控方明确选择权限，获准后自动开启；支持会话中重新申请控制和本地暂停 |
| 输入诊断 | 发送被控端执行成功或失败的反馈，失败保留视频连接 |
| 文件 | 双向分块、进度、接收方选择路径、取消、SHA-256 校验、断线残片清理 |
| 排队 | 只保留最新待显示帧及最新待发送鼠标移动；离散控制事件队列有上限 |
| 会话 | 8 秒连接超时、30 秒确认超时、心跳与读写超时、断线释放按键/鼠标 |
| 认证 | 临时码或 PBKDF2 密码派生凭证，双随机数、分角色 HMAC-SHA256 双向验证 |
| 加密 | 由 Tailscale 提供链路端到端加密；应用层没有额外 TLS。回环测试只在本机传输 |
| 监听 | 仅允许本机 Tailscale 网卡 IPv4 或回环地址；控制方输入 IPv4 |

当前已支持把被控电脑的文本剪贴板实时同步到 Windows、iOS 和 Android 控制端；文件内容仍使用文件传输。尚未实现音频、多屏切换、硬件视频编码、完整登录界面控制、Windows 安装器/代码签名和自动更新。

普通权限程序受 Windows 输入完整性级别限制，对管理员窗口的控制可能被阻止；UAC 安全桌面、锁屏及受保护画面不在当前支持范围。普通字符和手机 IME 使用 Unicode 文本注入，Ctrl/Alt/功能键使用虚拟键；Alt+Tab 等系统保留组合键仍可能被控制端 Windows 优先处理。

Tailscale 组网连接与本应用的远控会话分别管理。应用连接不代表已有控制许可；权限由被控端明确选择，控制端还可主动暂停。被控端点击停止是立即结束控制的入口。
